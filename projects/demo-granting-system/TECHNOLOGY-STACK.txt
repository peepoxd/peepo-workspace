================================================================================
                            DATA FLOW SUMMARY
================================================================================

1. USER REQUEST
   Browser → Traefik (port 80)

2. ROUTING
   /api/*   → Backend (Express, port 3000)
   /*       → Nginx → Static files (React SPA)

3. BACKEND PROCESSING
   Express → Middleware (auth, validation) → Route Handler

4. DATA ACCESS
   Handler → Redis (cache check)
          → PostgreSQL (query)
          → MinIO (file operations)

5. RESPONSE
   Handler → Middleware → Express → Traefik → Browser
