│   │   ├── กรอกข้อมูลโครงการ
│   │   ├── กำหนดวัตถุประสงค์
│   │   ├── กำหนดงบประมาณ
│   │   ├── กำหนดระยะเวลา
│   │   └── แนบเอกสาร
│   │

│   │   └── สถานะ: "รอคัดกรอง"
│   │
│   └── [นักวิชาการ] คัดกรองขั้นต้น
│       ├── ✅ ผ่าน → ไป Phase 2
│       ├── ❌ ไม่ผ่าน → ปฏิเสธ (จบ)

├── Phase 2: กลั่นกรอง & อนุมัติ
│   │
│   ├── [นักวิชาการ] กลั่นกรองทางวิชาการ
│   │   ├── ตรวจสอบความเหมาะสม
│   │   ├── กำหนดยุทธศาสตร์
│   │   ├── กำหนดแผนงบประมาณ
│   │   ├── *** กำหนดงวดเงิน ***
│   │   │   ├── งวดที่ 1: XX% (เริ่มโครงการ)
│   │   │   ├── งวดที่ 2: XX% (ส่งรายงาน 1)
│   │   │   ├── งวดที่ 3: XX% (ส่งรายงาน 2)
│   │   │   └── งวดที่ N: XX% (ปิดโครงการ)
│   │   └── เสนอพิจารณาอนุมัติ
│   │
│   └── [ผู้มีอำนาจอนุมัติ] พิจารณาอนุมัติ
│       ├── ✅ อนุมัติ → ไป Phase 3
│       ├── ❌ ไม่อนุมัติ → ปฏิเสธ (จบ)
│       └── 🔄 ส่งกลับแก้ไข → นักวิชาการ → ภาคี
│
├── Phase 3: ทำสัญญา
│   │
│   ├── [ศูนย์สัญญา] ตรวจสอบคุณสมบัติภาคี
│   │   ├── ✅ ผ่าน → ตรวจสัญญา
│   │   └── ❌ ไม่ผ่าน → ขอเอกสารเพิ่ม
│   │
│   ├── [ศูนย์สัญญา] ตรวจสอบสัญญา & ไฟล์แนบ
│   │   ├── ✅ ผ่าน → ส่งลงนาม
│   │   └── 🔄 ส่งกลับแก้ไข
│   │
│   ├── [ภาคี] ลงนามสัญญา (อิเล็กทรอนิกส์)
│   │
│   ├── [ผู้มีอำนาจอนุมัติ] ลงนามสัญญา (อิเล็กทรอนิกส์)
│   │
│   └── [ศูนย์สัญญา] บันทึก "ผ่านการทำสัญญา"
│       └── สถานะ: "ดำเนินการ" → ไป Phase 4
│
├── Phase 4: เบิกจ่าย & ส่งงาน (Loop ตามงวด)
│   │
│   ├── 🔁 วนซ้ำทุกงวด (งวด 1, 2, 3, ... N)
│   │   │
│   │   ├── [ภาคี] ขอเบิกเงินงวด
│   │   │   ├── ส่งรายงานความก้าวหน้า
│   │   │   └── แนบหลักฐานการใช้จ่าย
│   │   │
│   │   ├── [นักวิชาการ] ตรวจสอบ
│   │   │   ├── ✅ ผ่าน → เสนออนุมัติ
│   │   │   └── 🔄 ส่งกลับแก้ไข → ภาคี
│   │   │
│   │   ├── [ผู้มีอำนาจอนุมัติ] อนุมัติเบิกจ่าย
│   │   │   ├── ✅ อนุมัติ → จ่ายเงิน
│   │   │   └── ❌ ไม่อนุมัติ → ส่งกลับ
│   │   │
│   │   └── [ระบบ] โอนเงินให้ภาคี
│   │       └── บันทึกประวัติการเบิกจ่าย
│   │
│   └── งวดสุดท้าย → ไป Phase 5
│
├── Phase 5: ปิดโครงการ
│   │
│   ├── [ภาคี] ส่งคำร้องขอปิดโครงการ
│   │   ├── ส่งรายงานสรุปโครงการ
│   │   └── ส่งรายงานครุภัณฑ์ (ถ้ามี)
│   │
│   ├── [นักวิชาการ] ตรวจสอบ
│   │   ├── ตรวจรายงานสรุป
│   │   ├── ตรวจครุภัณฑ์
│   │   └── เสนอปิดโครงการ
│   │
│   └── [ศูนย์สัญญา] อนุมัติปิดโครงการ
│       └── สถานะ: "ปิดโครงการ" ✅ (จบ)
│
└── กรณีพิเศษ (แยกออกจาก Flow ปกติ)
    │
    ├── 🟡 ระงับโครงการ (Suspend)
    │   ├── [นักวิชาการ] เสนอระงับ + เหตุผล
    │   ├── [ผู้มีอำนาจอนุมัติ] อนุมัติระงับ
    │   │   ├── ✅ อนุมัติ → สถานะ: "ระงับชั่วคราว"
    │   │   └── ❌ ไม่อนุมัติ → กลับดำเนินการปกติ
    │   └── [ผู้มีอำนาจอนุมัติ] ยกเลิกการระงับ → กลับ Phase 4
    │
    └── 🔴 ยกเลิกโครงการ (Cancel)
        ├── [ภาคี/นักวิชาการ] ส่งคำร้องขอยกเลิก + เหตุผล
        ├── [นักวิชาการ] ตรวจสอบ + เสนอฝ่ายกฎหมาย
        └── [ฝ่ายกฎหมาย] พิจารณา
            ├── ✅ อนุมัติ → สถานะ: "ยกเลิก" (จบ)
            └── ❌ ไม่อนุมัติ → กลับดำเนินการ
