## What Was Built (5 Iterations)

**Iteration 1-2: Infrastructure & Core Backend**
- Docker Compose with 6 services (Traefik, Nginx, Backend, Redis, PostgreSQL, MinIO)
- Load balancer with health checks, rate limiting, circuit breaker
- Express backend with JWT authentication and RBAC (5 roles)
- Redis caching with TTL policies (Session 30m, API 1m, Dashboard 5m)

**Iteration 3: Complete Backend APIs**
- All 9 API modules implemented: auth, proposals, screening, approval,
  contracts, payments, dashboard, reports, files
- Zod validation schemas for all inputs
- MinIO file storage service integration

**Iteration 4: Database & Seeds**
- PostgreSQL schema with 7 tables + indexes
- Demo users (8 accounts for all 5 roles)
- Sample proposals for testing

**Iteration 5: Frontend Foundation**
- React 18 + TypeScript + Vite + TailwindCSS
- Zustand state management with RBAC helpers
- Login page with demo user quick-select
- Dashboard with KPIs and budget visualization
- Proposals list and create form
- Responsive sidebar navigation

## Remaining Work (3 Iterations)

**Iteration 6**: Complete frontend pages (Screening, Approval, Contracts, Payments)
**Iteration 7**: File upload UI, Reports export, Polish
**Iteration 8**: Playwright E2E tests, Load testing with k6

┌─────────────────────────────────────────────────────────────────────────────┐
│ # │ Principle                        │ Applied / การนำไปใช้                │
├───┼──────────────────────────────────┼─────────────────────────────────────┤
│ 1 │ Define "roles" before tech       │ ✅ Each layer has clear owner, SLA, │
│   │ นิยามหน้าที่ก่อนเลือกเทคโนโลยี       │    and failure mode                │
├───┼──────────────────────────────────┼─────────────────────────────────────┤
│ 2 │ Separate traffic from logic      │ ✅ Nginx/Traefik separate from      │
│   │ แยกรับทราฟฟิกจากประมวลผล           │    Node.js business logic          │
├───┼──────────────────────────────────┼─────────────────────────────────────┤
│ 3 │ LB = risk control tool           │ ✅ Health check, timeout, circuit   │
│   │ LB = เครื่องมือควบคุมความเสี่ยง      │    breaker configured              │
├───┼──────────────────────────────────┼─────────────────────────────────────┤
│ 4 │ Cache with metrics               │ ✅ TTL by data type, Redis with     │
│   │ Cache ต้องมีตัวเลขกำกับ             │    memory fallback                 │
├───┼──────────────────────────────────┼─────────────────────────────────────┤
│ 5 │ Protect DB from app              │ ✅ Connection pool, separate layer  │
│   │ ปกป้อง DB จากแอป                   │                                    │
├───┼──────────────────────────────────┼─────────────────────────────────────┤
│ 6 │ Separate file storage            │ ✅ MinIO (S3) separate from backend │
│   │ แยก file storage                  │                                    │
├───┼──────────────────────────────────┼─────────────────────────────────────┤
│ 7 │ Design for failure               │ ✅ Graceful error handling,         │
│   │ ออกแบบรองรับการล่ม                 │    cache fallback, no cascade      │
└───┴──────────────────────────────────┴─────────────────────────────────────┘
