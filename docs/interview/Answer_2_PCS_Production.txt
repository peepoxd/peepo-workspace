📄 ระบบ PCS (Production Control System) — ระบบควบคุมการผลิตแบบครบวงจร
│
├─ 📋 1. OVERVIEW (ภาพรวมระบบ) [10% ของหน้า]
│  ├─ วัตถุประสงค์
│  │  └─ บริหารจัดการการผลิตครบวงจร (รับ Order → วางแผน → ผลิต → จัดส่ง)
│  ├─ ผู้ใช้งานหลัก (6 กลุ่ม)
│  │  ├─ ฝ่ายขาย (Sale) — รับ Order, ออก Invoice
│  │  ├─ ฝ่ายวางแผน (Planning) — MRP, Production Plan
│  │  ├─ ฝ่ายผลิต (Production) — Work Order, บันทึกผลผลิต
│  │  ├─ ฝ่ายจัดซื้อ (Purchase) — PR, PO, รับวัตถุดิบ
│  │  ├─ คลังสินค้า (Warehouse) — Stock IN/OUT, Inventory
│  │  └─ ฝ่ายจัดส่ง (Shipment) — Delivery, Shipment Tag
│  └─ ข้อมูลโครงการ (สำหรับ PM)
│     ├─ ระยะเวลาพัฒนา: 10-12 เดือน
│     ├─ งบประมาณ: 8-15 ล้านบาท
│     └─ วิธีการ: Agile methodology (2-week sprint)
│

│  ├─ Phase 1: Sales Order Management
│  │  ├─ ลูกค้าส่ง Order (Customer Order)

│  │  ├─ สร้าง Delivery Note
│  │  └─ เปรียบเทียบ Order vs Shipment
│  │
│  ├─ Phase 2: Production Planning (MRP)
│  │  ├─ MRP Production — คำนวณความต้องการผลิต
│  │  ├─ Production Plan — วางแผนการผลิต
│  │  ├─ MRP Purchase — คำนวณความต้องการวัตถุดิบ
│  │  └─ สร้าง Work Order / Inspection
│  │
│  ├─ Phase 3: Procurement (จัดซื้อวัตถุดิบ)
│  │  ├─ Purchase Plan — แผนจัดซื้อ
│  │  ├─ Purchase Request (PR) — ใบขอซื้อ
│  │  ├─ Purchase Order (PO) — ใบสั่งซื้อ
│  │  ├─ Purchase Received — รับวัตถุดิบ
│  │  └─ Stock IN (Material) — นำเข้าคลัง
│  │
│  ├─ Phase 4: Production Execution
│  │  ├─ Production Tag — ป้ายงานผลิต
│  │  ├─ Work Result — บันทึกผลการผลิต
│  │  ├─ Production Result (JFG) — ผลผลิตสำเร็จรูป
│  │  ├─ Production Result (Material) — วัตถุดิบที่ใช้
│  │  └─ Handy Device — บันทึกผ่านมือถือ/Scanner
│  │
│  ├─ Phase 5: Inventory & Shipment
│  │  ├─ Stock Warehouse — จัดการคลัง
│  │  ├─ Stock IN/OUT — รับ-จ่ายสินค้า
│  │  ├─ Shipment Tag — ป้ายจัดส่ง
│  │  ├─ Shipment Result (JFG) — บันทึกการจัดส่ง
│  │  └─ Invoice — ออกใบแจ้งหนี้
│  │
│  └─ กรณีพิเศษ
│     ├─ Production Rework (งานซ่อม/ทำใหม่)
│     ├─ Material Return (คืนวัตถุดิบ)
│     └─ Order Cancellation (ยกเลิก Order)

├─ ⚠️ 6. RISKS & MITIGATION (ความเสี่ยง) [10% ของหน้า]
│  │
│  ├─ Risk 1: MRP คำนวณไม่แม่นยำ
│  │  └─ Mitigation: ปรับ Parameter ตาม Historical Data, Review รายสัปดาห์
│  ├─ Risk 2: Production หยุดชะงัก
│  │  └─ Mitigation: Offline Mode สำหรับ Handy, Auto-sync เมื่อกลับมา Online
│  ├─ Risk 3: Stock ไม่ตรงกับระบบ
│  │  └─ Mitigation: Barcode/QR Scan ทุกการเคลื่อนไหว, Stock Count รายเดือน
│  ├─ Risk 4: Integration กับ ERP เดิมล้มเหลว
│  │  └─ Mitigation: API Testing, Parallel Run 2 เดือน
│  └─ Risk 5: User ไม่คุ้นเคยระบบใหม่
│     └─ Mitigation: Training แยกตาม Role, Super User ประจำแผนก
│
├─ ✨ 7. SUCCESS FACTORS (ปัจจัยสำเร็จ) [10% ของหน้า]
│  │
│  ├─ 1. Real-time Visibility
│  │  └─ ดูสถานะการผลิต, Stock, Order ได้ทันที
│  ├─ 2. Accurate Planning
│  │  └─ MRP แม่นยำ ลดการขาด/เกิน Stock
│  ├─ 3. Traceability
│  │  └─ ติดตามย้อนกลับได้ทุก Lot (Material → Product → Shipment)
│  ├─ 4. Efficiency
│  │  └─ ลดเวลา Lead Time 20%, ลด Manual Entry 80%
│  └─ 5. Integration
│     └─ เชื่อมต่อ ERP, Accounting, Supplier Portal ได้
│

🎯 จุดเด่นของระบบ PCS:

1. End-to-End Flow — ครบตั้งแต่ Order ถึง Shipment
2. MRP Integration — คำนวณความต้องการผลิต+จัดซื้ออัตโนมัติ
3. Real-time Tracking — ติดตามทุกขั้นตอนผ่าน Dashboard
4. Traceability — ย้อนกลับได้ทุก Lot/Batch
5. Multi-device — รองรับ Web + Handy Device (Scanner)

💡 คำศัพท์สำคัญ:

- PCS = Production Control System
- MRP = Material Requirements Planning
- JFG = Just Finished Goods (สินค้าสำเร็จรูป)
- PR = Purchase Request (ใบขอซื้อ)
- PO = Purchase Order (ใบสั่งซื้อ)
- Work Order = ใบสั่งผลิต
- Production Tag = ป้ายงานผลิต (Barcode/QR)
- Handy = อุปกรณ์ Scanner มือถือ
