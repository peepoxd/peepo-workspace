💡 เคล็ดลับการออกแบบ 1 หน้า A4:

1. ใช้ Visual มากกว่า Text (Ratio 60:40)
   - Diagram สำหรับ Workflow
   - Table สำหรับ Modules & RBAC
   - Layered box สำหรับ Architecture

2. Typography Hierarchy
   - Title: 32-36pt, สีเข้ม, Bold
   - Section: 28pt, สี color-coded
   - Content: 22-24pt, ปกติ

3. Color Coding
   - ฟ้า: Overview, Workflow
   - เขียว: Modules, Success
   - แดง/ส้ม: Risks, RBAC
   - ม่วง: Architecture

4. Spacing & Margins
   - ขอบ: 0.5-0.75 นิ้ว
   - ระหว่าง section: 80-120pt
   - ภายใน section: 40-60pt

5. Professional Elements
   - Header: ข้อสอบ + ตำแหน่ง + หน่วยงาน
   - Footer: ชื่อ + วันที่ + เลขหน้า
   - กรอบ/เงาเล็กน้อยสำหรับ highlight
