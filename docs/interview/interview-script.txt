[2] อธิบายระบบ สสส.
--------------------------------------------------------------------------------

"ระบบ สสส. เป็น Grant Management ครับ

Workflow: ข้อเสนอ → คัดกรอง → อนุมัติ → สัญญา → เบิกจ่าย → ปิดโครงการ

ผู้ใช้ 5 กลุ่ม: ภาคีเครือข่าย, นักวิชาการ, ผู้อนุมัติ, ศูนย์สัญญา, กฎหมาย

จุดเด่น:
- เชื่อมต่อ GFMIS (การเงินภาครัฐ), e-GP (จัดซื้อจัดจ้าง)
- ลงนามอิเล็กทรอนิกส์ ลดกระดาษ 80%
- PDPA compliance"

================================================================================

[3] อธิบายระบบ PCS
--------------------------------------------------------------------------------

"ระบบ PCS เป็น Production Control ครับ

Workflow: Order → MRP → Purchase → Production → Shipment

ผู้ใช้ 6 กลุ่ม: ฝ่ายขาย, วางแผน, ผลิต, จัดซื้อ, คลัง, จัดส่ง

จุดเด่น:
- MRP คำนวณความต้องการวัตถุดิบอัตโนมัติ
- Handy Scanner บันทึกผลผลิต real-time
- Offline Mode ทำงานได้แม้ network ขัดข้อง
- Redis สำหรับ Real-time Dashboard"

[4] คำถาม Technical
--------------------------------------------------------------------------------

Q: ทำไมเลือก PostgreSQL?
A: "Open-source, ACID compliance, JSON support, Full-text search"

Q: ทำไมใช้ Agile?
A: "Stakeholders หลายกลุ่ม ต้องการ feedback เร็ว ส่ง MVP ก่อนได้"

Q: MRP คืออะไร?
A: "Material Requirements Planning - คำนวณว่าต้องซื้อวัตถุดิบอะไร เมื่อไหร่
   โดยดูจาก Order + BOM + Stock + Lead Time"

Q: ทำไมแยก 5 Layer?
A: "Separation of Concerns, Scalability, Security, Testability"

Q: Redis ใช้ทำอะไร?
A: "Session cache, MRP cache, Real-time dashboard, Queue"
