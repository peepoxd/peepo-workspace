# Inbox Example

> Folder นี้เก็บข้อมูลที่รับเข้ามาจากภายนอก

## ไฟล์ที่เก็บได้

`.md` `.txt` `.pdf` `.png` `.jpg` `.json` `.csv` — อะไรก็ได้

## ตัวอย่างสิ่งที่ใส่ได้

```
inbox/
├── reading-list.md          # ลิงก์ที่อยากอ่าน
├── meeting-notes-jan30.txt  # Notes จาก meeting
├── design-mockup.png        # รูปที่ได้รับมา
├── api-spec.pdf             # Spec จาก client
└── ideas.md                 # ไอเดียที่ได้ยินมา
```

---

*ลบไฟล์นี้ได้เมื่อเข้าใจแล้ว*
