# Archive Example

> Folder นี้เก็บของที่เสร็จแล้ว หรือของเก่าที่ต้องการเก็บไว้

## ไฟล์ที่เก็บได้

**อะไรก็ได้** — ทุกอย่างที่เคยอยู่ folder อื่นมาก่อน

## ตัวอย่างโครงสร้าง

```
archive/
├── projects/
│   └── 2026-01-website-redesign/
│       ├── final-design.figma
│       ├── index.html
│       └── retrospective.md
├── writing/
│   └── published-blog-post.md
├── lab/
│   └── concluded-experiment.py
└── 2026-01-old-config.json
```

## หลักการ

**แทนที่จะลบ → ย้ายมาที่นี่**

เก็บ history ไว้ — อาจต้องการดูอีกทีหลัง

---

*ลบไฟล์นี้ได้เมื่อเข้าใจแล้ว*
