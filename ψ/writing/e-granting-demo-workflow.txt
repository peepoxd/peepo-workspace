ใช้ Playwright ใน 2 รูปแบบ:

┌─────────────────────────────────────────────────────────────────────────────┐
│  รูปแบบ A: VALIDATION ใน RALPH LOOP                                         │
│  (ตรวจสอบระหว่างทำงาน)                                                       │
├─────────────────────────────────────────────────────────────────────────────┤
│                                                                             │
│  Ralph Loop Iteration N:                                                    │
│      │                                                                      │
│      ├─── 1. เปิด Browser                                                   │
│      │        browser_navigate: { url: "http://localhost:3000" }           │
│      │                                                                      │
│      ├─── 2. Snapshot (ดูโครงสร้างหน้า)                                     │
│      │        browser_snapshot: {}                                          │
│      │        → ได้ accessibility tree + element refs                      │
│      │                                                                      │
│      ├─── 3. Test Login Flow (ภาคี role)                                   │
│      │        browser_fill_form:                                            │
│      │        ├── email: "partner@test.com"                                │
│      │        └── password: "****"                                         │
│      │        browser_click: { ref: "button#login" }                       │
│      │                                                                      │
│      ├─── 4. Test Create Proposal                                          │
│      │        browser_navigate: { url: "/proposals/new" }                  │
│      │        browser_fill_form:                                            │
│      │        ├── project_name: "โครงการทดสอบ"                              │
│      │        ├── budget: "500000"                                         │
│      │        └── duration: "6"                                            │
│      │        browser_click: { ref: "button#submit" }                      │
│      │                                                                      │
│      ├─── 5. Verify Success                                                │
│      │        browser_wait_for: { text: "บันทึกสำเร็จ" }                    │
│      │        browser_snapshot: {} → ตรวจ state ใหม่                        │
│      │                                                                      │
│      └─── 6. Result                                                        │
│           ├── Pass → ไป iteration ถัดไป                                     │
│           └── Fail → Claude แก้โค้ด → วนใหม่                                │
│                                                                             │
└─────────────────────────────────────────────────────────────────────────────┘
