# Writing Example

> Folder นี้เก็บ drafts ที่กำลังเขียน

## ไฟล์ที่เก็บได้

`.md` `.txt` `.docx` `.tex` `.html` — งานเขียนทุกรูปแบบ

## ตัวอย่างสิ่งที่ใส่ได้

```
writing/
├── blog-post-draft.md       # Blog draft
├── proposal-v2.docx         # Proposal ที่กำลังแก้
├── readme-wip.md            # README ที่ยังไม่เสร็จ
├── presentation-notes.txt   # Notes สำหรับ talk
└── paper.tex                # Academic paper
```

---

*ลบไฟล์นี้ได้เมื่อเข้าใจแล้ว*
